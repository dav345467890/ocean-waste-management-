# 03 — Data Cleaning

Files for this stage:

- `clean_data_script.py` — validates and cleans source records, derives total waste, expected ocean waste, reporting gap, and rate metrics, and flags anomalies.
- `cleaned_ocean_waste_data.xlsx` — supplied cleaned workbook.

The Python script accepts a CSV input. Export the raw workbook sheet to CSV before running it, or provide the corresponding CSV path as the first argument.
